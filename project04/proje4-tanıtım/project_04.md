## Proje 4: Unsupervised Learning & Natural Language Processing (NLP)

### Senaryo:

Web'den kazıdığınız veya internet kaynaklarından elde ettiğiniz verileri kullanarak, unsupervised learning teknikleri ile verilerimiz hakkında neler öğrenebiliriz?


#### Veri Seti:

 * **Tipi**: Metin Verisi
 * **Elde Etme Yöntemi**: API, web scraping, diğer kaynaklar
 * **Depolama**: MongoDB
 

#### Araçlar:

 * Unsupervised Learning (`k-means`)
 * NLP (`nltk`, `gensim`, `textblob`, `spacy`)
 * Boyut Azaltma (`pca`, `svd`, `lda`)
 * NoSQL Veritabanları (`mongodb`)
 * Topic Modelling
 * Öneri Sistemleri
 * Web Arayüzü Geliştirme (`streamlit`, `flask`)


#### Analiz:

 * Unsupervised Learning (Clustering ve/veya NLP), Topic Modelling ve Öneri Sistemleri (Opsiyonel)


#### Teslim Süreci:

 * Grup Yapısı (2-3 kişilik) 
 * Sunum Dosyası (hem görsel hem sözlü anlatım)
 * Projeye Ait Repository
 * İnternette Yayınlanacak Blog Yazısı (Medium,...)
